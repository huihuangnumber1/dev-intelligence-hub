# PR 推进员工主模型与备选

用户要求 Codex `gpt-5.6-luna` 作为 PR 推进员工的主模型，Ollama 作为备选，
完成后继续自动流程修复。当前旧岗位只支持 Ollama；正式代码 Review 仍属于 PR 工程师。

增加可选 `employees.prReviewer.primaryBrain`，复用受控 BrainRouter、原生登录、
有限并发和实体隔离。既有 `brain` 保留为 Ollama 配置；旧配置行为不变。
主模型的需求和代码数据授权必须显式满足，配置通过版本化激活生效。

仅在已结束的模型可用性、传输、超时或输出错误后回退一次。用户取消、维护围栏、
授权拒绝、来源变化以及停止/清理不确定不得触发备选。主模型超时须等待受控
进程停止；备选也失败时记录真实失败。记录实际使用模型和回退原因。

复用现有裁剪、提示和结果校验，不增加 GitHub 写入权限，不重新开启用户暂停任务。
验证主模型成功、失败回退、取消与停止边界、配置往返、实际 Codex 调用，
独立审查后与原修复合并，托管部署并继续真实 PR 验收。
